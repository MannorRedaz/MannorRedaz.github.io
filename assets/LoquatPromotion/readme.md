冕宁枇杷·产地助农宣传站
定位：信息展示型助农网站，不是电商商城。
核心目的：把冕宁枇杷产地、农户、产品向外曝光，对接普通消费者、外地采购商、采摘游客，解决山区农产品“好货名气小、对外信息少”的痛点，贴合乡村振兴，适合大创、课程网页、竞赛项目。
一、网站核心理念

冕宁锦屏镇早春枇杷品质很好，但地处山区，对外宣传渠道有限，很多外面的人不知道这个产地。
这个网站不做真实下单支付，只做信息桥梁：

1. 对外讲清楚：冕宁枇杷为什么好吃；

2. 展示果园、农户真实故事；

3. 给到采购咨询、采摘联系渠道；

4. 帮助产地提升知名度，间接带动鲜果销售、采摘旅游。
学生项目重点：宣传展示，而非交易售卖，规避支付、货源、售后等现实难题。
二、目标访问人群（三类用户）

1. 普通消费者：想了解高山早春枇杷，想买鲜果、想学习挑选保存方法

2. 采购商/批发商：想找产地货源，批量拿货，需要产地环境、产量、成熟时间信息

3. 游客：想来果园采摘，想知道采摘时间、路线、果园位置
